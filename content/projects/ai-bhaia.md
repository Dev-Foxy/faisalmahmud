## The brief

Students following the NCTB syllabus needed a study companion that explains concepts in their own context and helps them actually remember what they learn.

## What I built

- Personalized AI tutoring aligned with the NCTB syllabus
- Active-recall practice to strengthen long-term memory
- A Python AI layer with a Node.js API and a React front end
